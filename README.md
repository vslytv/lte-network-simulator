# lte-network-simulator

# Моделирование планировщика ресурсов сети LTE

Симуляция алгоритмов планирования радиоресурсов (PRB) в сотовой сети LTE на уровне MAC. 
Реализовано три классических алгоритма планирования, проведено сравнение по пропускной способности и справедливости распределения ресурсов.

## Описание проекта

Проект демонстрирует работу планировщика ресурсов базовой станции (eNodeB) в сети LTE. 
В течение 1000 TTI (1 секунда) моделируется распределение 50 физических ресурсных блоков (PRB) 
между 20 пользователями (UE), расположенными в зоне покрытия трёх сот.

**Основные этапы:**
1. Размещение базовых станций и пользователей на карте.
2. Расчёт затухания сигнала (Path Loss) и SINR для каждого пользователя.
3. Определение потенциальной скорости на один PRB (формула Шеннона).
4. Итеративное планирование ресурсов тремя алгоритмами.
5. Сравнение результатов по пропускной способности и индексу Джейна.

## Алгоритмы планирования

В работе сравниваются три классических алгоритма:

| Алгоритм | Принцип | Цель |
|---|---|---|
| **Max C/I** | Ресурс отдаётся пользователю с наилучшим каналом | Максимизация суммарной пропускной способности |
| **Proportional Fair (PF)** | Максимизация отношения мгновенной скорости к средней | Баланс между эффективностью и справедливостью |
| **Round Robin (RR)** | Циклическое распределение по очереди | Максимальная справедливость |

## Ключевые формулы

**Спектральная эффективность (формула Шеннона):**

$$
SE = \min\!\Big(\log_2(1 + \text{SINR}_{\text{lin}}) \times \eta,\; SE_{\max}\Big)
$$

**Биты на PRB за один TTI:**

$$
\text{bits} = SE \times BW_{\text{PRB}} \times T_{\text{TTI}}
$$

**Path Loss:**

$$
PL(d) = PL_0 + 10\,n\,\log_{10}\!\left(\frac{d}{d_0}\right) + \mathcal{N}(0,\,\sigma)
$$

**Индекс Джейна (мера справедливости):**

$$
J = \frac{\left(\sum_{i=1}^{N} x_i\right)^2}{N \cdot \sum_{i=1}^{N} x_i^2}
$$

> \( J = 1 \) — идеальная справедливость, \( J = 1/N \) — максимальная несправедливость.

## Результаты

В ноутбуке представлены:

- **Карта покрытия** (RSRP) для области 3×3 км с шагом 10 м.
- **Распределение SINR** по 20 пользователям.
- **Потенциал пользователей** — биты на один PRB за один TTI.
- **Пропускная способность** каждого пользователя за 1 с для трёх алгоритмов.
- **Тепловые карты** выделения PRB по TTI для каждого алгоритма.
- **Индекс Джейна** — итоговое сравнение справедливости.
